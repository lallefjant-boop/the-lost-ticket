# The Lost Ticket

Download page for **The Lost Ticket**, a free scratch-card desk game for Mac and Windows.

**Website:** https://lallefjant-boop.github.io/the-lost-ticket/
**Downloads:** see [Releases](https://github.com/lallefjant-boop/the-lost-ticket/releases/latest) (each file's SHA-256 is listed in `SHA256SUMS.txt`).

This repository contains only the static download page (no tracking, no third-party requests).
The font is Pixelify Sans (SIL Open Font License 1.1, see `img/OFL-PixelifySans.txt`).
